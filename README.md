# 📱 Responsive Web Layout

A responsive website developed using **HTML5** and **CSS3** as part of the **DecodeLabs Frontend Development Industrial Training Program (Batch 2026)**.

## 📖 About the Project

This project demonstrates responsive web design principles by creating a webpage that adapts seamlessly across desktops, tablets, and mobile devices. It focuses on building flexible layouts using modern CSS techniques while maintaining a clean and user-friendly interface.

## ✨ Features

- Responsive layout
- Mobile-first design
- CSS Media Queries
- Flexbox & CSS Grid
- Clean and modern UI
- Cross-browser compatibility

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## 🚀 Getting Started

1. Clone the repository

```bash

```

2. Open the project folder.

3. Launch `index.html` in your browser.
